1) Enable Email/Password auth

Firebase Console → Authentication → Sign-in method → enable Email/Password → Users → Add user (your admin email + password). Then sign in on this page.

2) Firestore security rules

Firebase Console → Firestore → Rules → paste this, then Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /settings/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /categories/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /apps/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /messages/{doc} { allow create: if true; allow read, update, delete: if request.auth != null; }
  }
}

3) Seed demo data (optional)

If Firestore is empty, one click copies the demo categories/apps from Index.html into the cloud.
